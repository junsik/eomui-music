# 설치와 사용

어머니 컴퓨터에 설치하는 방법입니다. **설치는 아들이 직접 해 드리는 편이 좋습니다** —
서명하지 않은 설치 파일이라 Windows가 경고 창을 띄우는데, 어머니 눈에는 바이러스 경고처럼 보입니다.

## 1. 설치

`eomui-music-setup.exe`를 실행합니다.

**SmartScreen 경고가 뜹니다.** "Windows의 PC 보호" 파란 창이 나오면
**추가 정보** → **실행**을 누르세요. 코드 서명 인증서가 유료라 붙이지 않았습니다.

설치 화면에서 두 가지를 고를 수 있습니다.

| 항목 | 권장 |
|---|---|
| 윈도우 시작할 때 자동으로 실행 | **켜기** — 컴퓨터를 켜면 알아서 실행됩니다 |
| 바탕화면에 아이콘 만들기 | 취향껏 |

설치 위치는 `%LOCALAPPDATA%\Programs\어무이음악\`입니다.
Program Files가 **아닙니다**. 이유는 [ARCHITECTURE.md](ARCHITECTURE.md#설치-위치)를 보세요.

설치 파일에 `yt-dlp` · `ffmpeg` · `deno`가 모두 들어 있어
**설치 직후 바로 쓸 수 있습니다.** 따로 내려받는 시간이 없습니다.

## 2. Chrome 확장 등록 (한 번만)

이 단계는 자동화할 수 없습니다. 크롬 정책상 웹스토어 밖의 확장은
수동으로 불러와야 합니다.

1. 시작 메뉴 → **어무이 음악 다운로더** → **크롬 확장 프로그램 폴더 열기**
   (또는 설치 폴더의 `크롬확장\` 폴더)
2. Chrome 주소창에 `chrome://extensions` 입력
3. 우측 상단 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램 로드** 클릭 → 위의 `크롬확장` 폴더 선택

확장 버전이 **1.4.0 이상**인지 확인하세요. 그보다 낮으면 다운로드가 거부됩니다.

## 3. 사용법

### 음악 받기

1. YouTube에서 듣고 싶은 영상을 엽니다
2. 좋아요·공유 버튼 옆의 **빨간 "MP3 다운로드"** 버튼을 누릅니다
3. 잠시 뒤 바탕화면에 MP3가 생깁니다

주소를 복사하거나 붙여넣을 필요가 없습니다.

### 받은 음악 듣기

바탕화면의 **어무이 음악 다운로더** 아이콘을 누르면 음악 목록 화면이 열립니다.

```
┌──────────────────────────────┐
│  ♪ 어무이 음악                │
│  ● 준비 완료                  │
├──────────────────────────────┤
│  [ ▶ 유튜브에서 음악 찾기 ]   │
├──────────────────────────────┤
│  아리랑                [듣기] │
│  2026-07-29 · 바탕화면        │
├──────────────────────────────┤
│  봄날은 간다           [듣기] │
│  2026-07-28 · 바탕화면        │
├──────────────────────────────┤
│  [ 더 보기 (18곡 남음) ]      │
│  [ 음악 폴더 열기 ]           │
│  [ 바탕화면 정리하기 ]        │
└──────────────────────────────┘
```

- 맨 위 **유튜브에서 음악 찾기** 버튼을 누르면 YouTube가 새 탭으로 열립니다.
  주소를 입력하실 필요가 없습니다
- **듣기** 버튼을 누르면 평소 쓰시는 음악 프로그램으로 재생됩니다
- 처음에는 최근 20곡만 보이고, **더 보기**로 이어서 봅니다.
  곡이 수백 개여도 첫 화면이 길어지지 않습니다
- 보관함으로 내려간 곡도 여기서는 똑같이 한 줄로 보이므로,
  **폴더를 찾아 들어갈 필요가 없습니다**

글씨와 버튼은 Windows 화면 배율 설정을 그대로 따라갑니다.
배율이 150%면 화면도 그만큼 커집니다.

프로그램이 꺼져 있어도 아이콘을 누르면 실행되면서 화면이 열립니다.
이미 켜져 있으면 화면만 열립니다.

## 프로그램 종료

트레이 아이콘(작업 표시줄 우측 하단 시계 옆) **우클릭 → 종료**.
아이콘이 안 보이면 `^` 를 눌러 숨은 아이콘을 펼치세요.

트레이 메뉴:

| 항목 | 하는 일 |
|---|---|
| 유튜브 열기 | YouTube를 브라우저로 엽니다 |
| 음악 목록 보기 | 받은 곡을 보고 듣는 화면을 엽니다 |
| 음악 폴더 열기 | 받은 음악이 있는 폴더를 엽니다 |
| 바탕화면 음악 정리 | 흩어진 MP3를 월별 보관함으로 정리합니다 |
| 로그 폴더 열기 | `eomui-music.log`가 있는 폴더 |
| 윈도우 시작할 때 자동 실행 | 자동 실행을 켜고 끕니다 |
| 종료 | 완전히 종료 |

## 바탕화면 음악 정리

받은 MP3가 쌓이면 바탕화면이 뒤덮입니다. 이 프로그램이 알아서 정리합니다.

```
바탕화면\
├── 아리랑.mp3            ← 최근 곡만 (기본 12곡)
├── 봄날은 간다.mp3
├── ...
└── 음악 보관함\
    ├── 2026년 07월\
    ├── 2026년 06월\
    └── 2026년 05월\
```

**남기는 기준** — 두 조건을 **모두** 만족해야 바탕화면에 남습니다.

- 받은 지 **30일** 이내
- 그중에서도 **최근 12곡**까지

**기준 바꾸기** — 설치 폴더의 `settings.json`을 메모장으로 열어 숫자를 고칩니다.
경로는 `%LOCALAPPDATA%\Programs\어무이음악\settings.json` 입니다.
고친 뒤에는 트레이에서 종료했다가 다시 실행해야 반영됩니다.

```json
{
  "desktopKeepCount": 12,
  "desktopKeepDays": 30
}
```

숫자를 늘리면 보관함에 있던 곡이 다시 바탕화면으로 올라옵니다.
화면 배율이 높아 아이콘이 몇 개 안 보이면 `desktopKeepCount`를 줄이세요.

**이미 쌓인 MP3 정리** — 트레이 우클릭 → **바탕화면 음악 정리**.
바탕화면에 흩어진 MP3를 파일 날짜 기준으로 위 규칙에 맞춰 정리합니다.
실행 전에 몇 개를 옮길지 확인 창이 뜹니다.

**직접 두신 파일은 건드리지 않습니다.** 이 프로그램이 받은 파일만 옮깁니다.
사진·문서·직접 넣은 MP3는 그대로 둡니다.

## 같은 노래를 또 누르면

다시 받지 않고 "이미 받으신 노래예요"라고 알려 줍니다.
파일을 지우셨으면 다시 받으실 수 있습니다.

## 문제 해결

### "서버 연결 안 됨"이 뜹니다

1. 트레이에 🎵 아이콘이 있는지 확인 (없으면 프로그램 재실행)
2. **아이콘에 마우스를 올려 툴팁을 확인하세요.** 원인이 적혀 있습니다
3. 포트 8080을 다른 프로그램이 쓰고 있는지 확인:
   ```powershell
   Get-NetTCPConnection -LocalPort 8080 -State Listen
   ```
   대개는 이 프로그램이 **이미 실행 중**인 경우입니다
4. 로그에서 오류를 확인합니다. 트레이 우클릭 → **로그 폴더 열기**가 가장 빠르고,
   경로로 직접 찾으려면 여기입니다:
   ```
   %LOCALAPPDATA%\Programs\어무이음악\eomui-music.log
   ```
   메모장으로 열면 됩니다. 전화로 안내하실 때는 어머니께
   "윈도우 키 + R → 위 경로 붙여넣기"보다 **트레이 메뉴 쪽이 훨씬 쉽습니다.**

### 프로그램을 실행해도 아무 반응이 없습니다

정상입니다. 창이 뜨지 않고 트레이 아이콘으로만 실행됩니다.

### "필수 파일을 준비하는 중입니다"가 계속 나옵니다

설치 파일로 설치했다면 나오지 않아야 합니다.
exe만 복사해서 쓰는 경우라면 `yt-dlp` · `ffmpeg` · `deno`를 내려받는 중입니다 (약 170MB).

방화벽이나 백신이 막으면 실패하고, `eomui-music.log`에
`[SETUP] ... 내려받기 실패`가 남습니다. 이때는 아래를 직접 받아
exe와 같은 폴더에 두세요.

- https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp.exe
- https://www.gyan.dev/ffmpeg/builds/ffmpeg-release-essentials.zip (ZIP 안 `bin/ffmpeg.exe`)
- https://github.com/denoland/deno/releases/latest/download/deno-x86_64-pc-windows-msvc.zip

### 어느 날 갑자기 다운로드가 안 됩니다

YouTube가 바뀌면 `yt-dlp`가 깨집니다. 이 프로그램은 **주 1회 자동으로 최신 버전을
확인**하므로 보통은 다시 시작하면 해결됩니다. 그래도 안 되면 트레이에서 종료 후
다시 실행해 `eomui-music.log`의 `yt-dlp` 관련 줄을 확인하세요.

## 제거

설정 → 앱 → **어무이 음악 다운로더** → 제거.

받으신 MP3는 **지워지지 않습니다.** 바탕화면과 `음악 보관함` 폴더에 그대로 남습니다.
