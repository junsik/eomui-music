# extension — Chrome 확장 (Manifest V3)

YouTube 영상 페이지의 액션바(좋아요·공유 옆)에 빨간 **MP3 다운로드** 버튼을
주입하고, 로컬에서 도는 앱에 다운로드를 요청합니다.

## 등록 방법

빌드가 필요 없습니다.

1. Chrome 주소창에 `chrome://extensions`
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램 로드** → 이 폴더 선택

설치 프로그램으로 설치한 경우에는 `설치폴더\크롬확장\` 을 선택하면 됩니다.

## 파일

| 파일 | 역할 |
|---|---|
| `manifest.json` | 권한과 진입점 |
| `content.js` | 액션바 탐색·버튼 주입, 다운로드 요청, 상태 표시 |
| `content.css` | 버튼과 상태 오버레이 스타일 |
| `popup.html` | 툴바 팝업 — 서버 상태와 사용법 |
| `icons/` | 16 / 48 / 128px 아이콘 |

## 앱과의 약속

`GET http://localhost:8080/api/download?url=...` 에 **`X-Eomui-Client: 1`**
헤더를 붙여 호출합니다. 이 헤더가 없으면 앱이 요청을 거부할 수 있습니다.
다른 웹사이트가 몰래 다운로드를 거는 것을 막기 위한 장치입니다
([docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md#보안-모델) 참고).

응답:

| 상태 | 뜻 |
|---|---|
| `200` + `duplicate: true` | 이미 받은 곡 — 다시 받지 않음 |
| `200` | 다운로드 성공 |
| `403` | 우리 확장의 요청이 아님 |
| `429` | 다른 곡을 받는 중 |
| `503` | 필수 파일 준비 중 (진행 상황이 메시지에 담김) |

앱이 헤더를 확인하므로 **앱과 확장은 함께 갱신**하세요.

## SPA 대응

YouTube는 페이지를 새로 불러오지 않고 화면만 바꿉니다. 액션바가 늦게 나타나면
500ms 간격으로 최대 30회까지 다시 찾습니다.
